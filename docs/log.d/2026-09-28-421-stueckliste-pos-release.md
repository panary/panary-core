* **Feature**: Jeder `pos-v*`-Tag bekommt eine CycloneDX-Stückliste des POS-Pakets mit npm- **und** Cargo-Graph in einer Datei ([#421](https://github.com/panary/panary-core/issues/421), [ADR 0051](../adr/0051-stueckliste-je-release-cyclonedx.md#pos-paket-pos-v-core421)). [`release-pos.yml`](../../.github/workflows/release-pos.yml) legt nach dem Windows-Build die tatsächlich benutzten Lockfiles ab (nicht das committete `pnpm-lock.yaml`, das der Job neu auflöst). Der neue Job `release-sbom` erzeugt daraus per syft `panary-pos-<version>.cdx.json`, prüft auf `tauri`, `rumqttc`, `mdns-sd` und `@angular/core` und hängt die Datei neben `latest.json` an das Release. Die npm-Seite ist eine Obermenge: Das Lockfile enthält auch Edge-Abhängigkeiten.
