* **Creation**: [Edge ohne Token-Schlüssel](../infrastructure/edge-token-schluessel.md) — `install.sh` erzeugt `EDGE_TOKEN_ENCRYPTION_KEY` (ersetzt einen vorhandenen nie) und reicht ihn im Compose durch, beide Repo-Composes verlangen ihn; der Edge verschlüsselt einen Klartext-`cloudToken` beim Boot nach, meldet falschen oder fehlenden Schlüssel laut und startet weiter (Erzwingen: [#1499](https://github.com/panary/panary-core/issues/1499)) ([#1498](https://github.com/panary/panary-core/issues/1498)).
