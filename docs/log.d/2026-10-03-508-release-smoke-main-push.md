* **CI**: Das Edge-Release-Image wird vor dem Push gestartet, und die Edge-Image-Prüfung läuft auf jedem `main`-Push ([#508](https://github.com/panary/panary-core/issues/508)). `build-edge-docker.yml` baut und lädt das Image erst, fährt `smoke-edge-image.sh` gegen die Release-Version und pusht nur bei Grün. So erreicht ein Image, das nicht bootet, weder `:latest` noch Watchtower. Der `main`-Lauf ohne Pfadfilter fängt Brüche durch reine Code-Änderungen, etwa einen Import aus `devDependencies`, den `pnpm prune --prod` im Image entfernt. [Leitfaden](../infrastructure/edge-image-pr-pruefung.md#im-release-vor-dem-push).
