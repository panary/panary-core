* **Update** ([#1438](https://github.com/panary/panary-core/issues/1438), Anker [#1411](https://github.com/panary/panary-core/issues/1411)): Der Edge kennt die Version jedes verbundenen Geräts. Der POS (und die übrigen Gerätetypen) sendet seine Build-Version als `clientVersion` im Socket-`auth`; `channels.ts` liest sie tolerant (fehlend, kein Text oder über 50 Zeichen = unbekannt, nie eine Abweisung), hält sie an der Connection und trägt sie ins Wide Event `device.auth` ein. `device-connections` gibt sie als `connectedDevices: { deviceId, clientVersion }[]` aus (Anmeldung und RBAC wie bisher), die öffentliche `/health` bleibt ohne Geräteliste. Die Spalten `posClientVersion` und `edgeAppVersion` bleiben unberührt. Doku in [Geräte-Online-Tracking](../domains/geraete-online-tracking.md) und im Nachtrag von [ADR 0070](../adr/0070-versions-kompatibilitaet-je-strecke.md).
