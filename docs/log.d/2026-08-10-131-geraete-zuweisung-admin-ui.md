* **Update**: [Zugewiesene POS-Geräte](../domains/pos-geraete-zuweisung.md) um die Pflege im **Edge-Admin** erweitert. Die Geräteliste bekommt eine Spalte „Zuweisung", eine Zeilen-Aktion mit Overlay im Stil des Pairing-Modals und dieselbe Auswahl im Pairing-Dialog. Das ist der wichtigere der beiden Admins: Gepairte POS-Geräte leben in der Edge-SQLite und werden nicht in die Cloud gesynct — im lokalen Hub-Betrieb gibt es gar keinen zweiten Ort.
* **Befund**: Die Warnung „letztes geteiltes Terminal" ist **beratend, keine Sperre**. Das Personalnummer-Stempel-Panel erscheint nur auf `shared`-Geräten; wird das letzte davon zugewiesen, hat der Standort keine Stempel-Station mehr. Gesperrt wird trotzdem nicht — es gibt legitime Aufstellungen ohne Stempel-Station, und das Dashboard-Statusmenü bleibt als Stempelpfad erhalten. Die Warnung zählt pro **Standort** und ignoriert inaktive Geräte.
* **Befund**: Das Echo aus Schritt 3 wird als **Fähigkeits-Sonde** benutzt: Fehlt `deviceAccessMode` in der `request-code`-Antwort, blendet die UI die Zuweisung aus. Ein älterer Edge würde die Auswahl beim Redeem stillschweigend verlieren — sie gar nicht erst anzubieten ist das ehrlichere Verhalten als eine Versionsabfrage, die beim nächsten Release wieder nachgezogen werden müsste.
* **Befund**: Beim Zurückschalten auf `shared` leert die UI die Liste mit. Eine stehengebliebene Liste sähe beim nächsten Blick in die Datenbank wie eine aktive Zuweisung aus.
